使用说明 / 使用說明 / HOW TO USE
================================

简体中文 · 繁體中文 · English —— 程序界面支持三种语言，首次启动会让你选。


一、三步开始
------------

【简体】
  1. 下载 SDL2.dll（可选）—— 地址见下面第二节
  2. 双击 launch.bat
  3. 托盘里操作：左键双击 = 暂停/恢复，右键 = 菜单

【繁體】
  1. 下載 SDL2.dll（選用）—— 網址見下方第二節
  2. 雙擊 launch.bat
  3. 托盤操作：左鍵雙擊 = 暫停/恢復，右鍵 = 選單

【English】
  1. Get SDL2.dll (optional) - see section 2
  2. Double-click launch.bat
  3. Tray: left double-click = pause/resume, right-click = menu

托盘图标会随状态变化，鼠标悬停可看到当前状态和累计敲击次数。

图标可能被 Windows 收进任务栏的 ∧ 里，去那里拖出来即可。
The icon may be hidden under the taskbar's ^ arrow - drag it out.

启动方式的区别：
  launch.bat  真正后台运行，关掉窗口不停（日常用这个）
  debug.bat   排错用，挂着窗口，关窗口就停
  stop.bat    彻底停止
  viewlog.bat 查看后台日志

  launch.bat  : real background, survives closing the window (use this)
  debug.bat   : for troubleshooting, tied to the window
  stop.bat    : stop everything
  viewlog.bat : read the background log


二、SDL2.dll 官方下载地址
------------------------

    https://github.com/libsdl-org/SDL/releases

取最新版的 SDL2-2.xx.x-win32-x64.zip（VC、64 位），
解压出 SDL2.dll，放进 sdl_runtime\ 或仓库根目录。

备用镜像 / Mirror: https://www.libsdl.org/download-2.0.php
（Windows 一栏，VC 行，64-bit）

【English】Take the latest SDL2-2.xx.x-win32-x64.zip (VC, 64-bit),
extract SDL2.dll into sdl_runtime\ or the repo root.

本仓库不附带 DLL，也不自动下载 —— 官方下载速度因人而异，地址给你自己下。
No DLLs are bundled and nothing is auto-downloaded; grab it yourself.

不放也能用：自动退回系统 XInput，Xbox 系手柄正常。
PS / Switch / 八位堂手柄才需要 SDL。
Optional: falls back to system XInput, works for Xbox-family pads.
Only PS / Switch / 8BitDo need SDL.


三、默认键位
------------

  A/B/X/Y、LB/RB、方向键  →  F13~F24（触发拍桌，不插字符）
  LT / RT                 →  鼠标左键 / 右键
  左摇杆                  →  移动鼠标
  Back + Start 长按 1 秒   →  暂停
  Ctrl + Alt + G          →  暂停

想让按键敲出字符来攒「字符数」，改 config.json 里对应项的 char。

六、它到底做了什么（技术说明）
------------------------------

  手柄 ──► SDL / XInput 轮询 ──► 归一化按钮·摇杆·扳机
                                        │
                                        ▼
                          合成键鼠事件（SendInput）
                          或直投窗口（PostMessage）
                                        │
                                        ▼
                                Wuwa Tappo（完全不知情）

  全程只在自己的进程里跑。默认走 post 通道，
  直接把消息投给桌宠窗口，不受最小化和焦点影响。

  Gamepad ──► SDL / XInput poll ──► normalized buttons, sticks, triggers
                                        │
                                        ▼
                          synthesized input (SendInput)
                          or post to the pet window (PostMessage)
                                        │
                                        ▼
                            Wuwa Tappo (completely unaware)

  Everything runs in its own process. Post mode is the default, so it
  keeps working while minimized or when another window has focus.


七、排错
--------

  托盘图标不出？ stop.bat → debug.bat，看实时报错
  后台出问题？   viewlog.bat，看 bridge.log
  手柄没反应？   托盘菜单 → 探测手柄
  最小化失效？   diagnose.bat，实测通道

  No tray icon?  stop.bat then debug.bat - errors print live
  Background trouble?  viewlog.bat reads bridge.log
  Pad not responding?  tray menu -> Probe gamepad
  Breaks when minimized?  diagnose.bat tests the channels


八、环境要求
------------

  Windows 10 / 11
  Python 3.10+（安装时勾选 "Add python.exe to PATH"）
  SDL2.dll（可选，自行下载）

  Zero third-party packages required for Xbox pads (XInput is built in).
